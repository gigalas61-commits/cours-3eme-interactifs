1. Qu’est-ce qu’une fonction ?

Une fonction est un procédé qui, à chaque nombre d’un ensemble de départ, associe un unique nombre.

On note généralement une fonction f, et on écrit :

Notation : f : x ↦ f(x)
On lit « f est la fonction qui à x associe f(x) ».

Vocabulaire essentiel

  • Image : f(x) est l’image de x par la fonction f.
  • Antécédent : x est un antécédent de f(x) par f.
  • Un nombre a toujours une seule image, mais peut avoir plusieurs antécédents (ou aucun).
Exemple : Soit f(x) = 2x + 3.
L’image de 4 est f(4) = 2 × 4 + 3 = 11.
11 est l’image de 4 par f. 4 est un antécédent de 11 par f.
Pour trouver l’image, on remplace x par la valeur donnée dans l’expression de f(x).

2. Lecture graphique

La courbe représentative d’une fonction f est l’ensemble des points de coordonnées (x ; f(x)).

Lire une image : à partir d’une valeur de x sur l’axe horizontal, on monte (ou descend) jusqu’à la courbe, puis on lit la valeur sur l’axe vertical.

Lire un antécédent : à partir d’une valeur de y sur l’axe vertical, on trace une horizontale ; chaque intersection avec la courbe donne un antécédent.
Un point M(a ; b) appartient à la courbe de f si et seulement si f(a) = b.

3. Tableau de valeurs

Un tableau de valeurs regroupe des couples (x ; f(x)). Il permet de représenter graphiquement une fonction en plaçant les points correspondants.

Méthode : Pour chaque valeur de x, on calcule f(x) et on reporte le résultat dans le tableau.

4. Fonctions linéaires

Une fonction linéaire est une fonction de la forme :

f(x) = ax
où a est un nombre appelé coefficient.

Propriétés

  • La représentation graphique est une droite passant par l’origine O(0 ; 0).
  • f(0) = 0 toujours.
  • Une situation de proportionnalité se traduit par une fonction linéaire.
  • Le coefficient a se calcule : a = f(x)x pour tout x ≠ 0.
Si a > 0, la fonction est croissante. Si a < 0, elle est décroissante.

Exercice

Soit f la fonction linéaire telle que f(3) = 12. Détermine le coefficient a.

Voir la correction
a = f(3)3 = 123 = 4.
Donc f(x) = 4x.

5. Fonctions affines

Une fonction affine est une fonction de la forme :

f(x) = ax + b
  • • a est le coefficient directeur (pente de la droite)
  • • b est l’ordonnée à l’origine (point où la droite coupe l’axe des ordonnées)

Cas particuliers

  • Si b = 0 : fonction linéaire f(x) = ax
  • Si a = 0 : fonction constante f(x) = b
Coefficient directeur : a = f(x2) − f(x1)x2 − x1 = ΔyΔx
L’ordonnée à l’origine b se lit directement sur le graphique : c’est la valeur de f(0).

Exercice 2 — Antécédents

Soit f(x) = 2x + 1. Quel est l’antécédent de 9 par f ?

Correction
On cherche x tel que f(x) = 9.
2x + 1 = 9 ⇒ 2x = 8 ⇒ x = 4.
L’antécédent de 9 par f est 4.

Exercice 3 — Fonction linéaire et proportionnalité

Le prix d’entrée à une piscine est de 3,50 € par personne.

a) Exprime le prix total P en fonction du nombre n de personnes.

b) Quel est le prix pour 8 personnes ?

€
Correction
a) P(n) = 3,5n — c’est une fonction linéaire de coefficient 3,5.
b) P(8) = 3,5 × 8 = 28 €.

Exercice 4 — Fonction affine

Un plombier facture 40 € de déplacement plus 25 € par heure de travail.

a) Détermine l’expression de f(t), le coût total en fonction du temps t (en heures).

b) Calcule le coût pour 3 heures de travail.

€
Correction
a) f(t) = 25t + 40 — fonction affine avec a = 25 et b = 40.
b) f(3) = 25 × 3 + 40 = 75 + 40 = 115 €.

Exercice 6 — Déterminer une fonction affine

Soit f une fonction affine telle que f(2) = 7 et f(5) = 16.

Détermine a et b tels que f(x) = ax + b.

Correction
a = 16 − 75 − 2 = 93 = 3.
f(2) = 3×2 + b = 7 ⇒ b = 7 − 6 = 1.
Donc f(x) = 3x + 1.
