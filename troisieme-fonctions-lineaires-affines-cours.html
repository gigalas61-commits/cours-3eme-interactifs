1. Fonction linéaire

Définition
Une fonction linéaire est une fonction de la forme f(x) = ax où a est un nombre réel appelé coefficient.

La fonction linéaire traduit une situation de proportionnalité : si l’on double la valeur de x, alors f(x) est aussi doublée.

Propriétés fondamentales

  • La courbe représentative est une droite passant par l’origine O(0 ; 0).
  • Le coefficient a est le coefficient directeur : il mesure la pente de la droite.
  • Si a > 0 la fonction est croissante ; si a < 0 elle est décroissante.
  • f(1) = a : le coefficient se lit directement à x = 1.
Astuce Brevet : Pour trouver le coefficient a à partir d’un point M(xM ; yM) de la droite, on calcule a = yMxM.

2. Fonction affine

Définition
Une fonction affine est une fonction de la forme f(x) = ax + b où a est le coefficient directeur et b l’ordonnée à l’origine.

Cas particuliers

  • Si b = 0 : f(x) = ax → fonction linéaire
  • Si a = 0 : f(x) = b → fonction constante

Rôle de a et b

Le coefficient directeur a détermine la pente de la droite :

  • a > 0 : la droite « monte » (fonction croissante)
  • a < 0 : la droite « descend » (fonction décroissante)
  • a = 0 : la droite est horizontale

L’ordonnée à l’origine b est la valeur de f(0). C’est le point où la droite coupe l’axe des ordonnées.

Calcul du coefficient directeur
À partir de deux points A(xA ; yA) et B(xB ; yB) : a = yB − yAxB − xA

Représentation graphique interactive

Faites varier a et b pour observer l’effet sur la droite représentative de f(x) = ax + b.

Méthode : Pour tracer f(x) = ax + b, placez d’abord le point (0 ; b), puis à partir de ce point avancez de 1 en x et de a en y.

3. Déterminer une fonction affine

À partir de deux points

Méthode
Soit A(xA ; yA) et B(xB ; yB) deux points de la droite.
1. Calculer a = yB − yAxB − xA
2. Calculer b = yA − a × xA

Exercice interactif : cliquez deux points

Cliquez sur le graphique pour placer deux points. La fonction affine passant par ces points sera calculée automatiquement.

Exemple résolu

Déterminer la fonction affine passant par A(1 ; 3) et B(4 ; 9)

Voir la correction

Étape 1 : Calcul de a

a = 9 − 34 − 1 = 63 = 2

Étape 2 : Calcul de b

b = yA − a × xA = 3 − 2 × 1 = 1

Conclusion : f(x) = 2x + 1

Vérification : f(4) = 2 × 4 + 1 = 9 ✓

4. Signe et variations

Signe de f(x) = ax + b

Règle
f(x) = ax + b s’annule pour x = −ba (avec a ≠ 0).
Le signe de f(x) dépend du signe de a.

Tableau de signes

Si a > 0 : f(x) est négative avant la racine, positive après.

Si a < 0 : f(x) est positive avant la racine, négative après.

Variations

  • Si a > 0 : f est strictement croissante sur ℝ
  • Si a < 0 : f est strictement décroissante sur ℝ
  • Si a = 0 : f est constante

Visualisation interactive

Observez les zones où f(x) est positive (bleu) ou négative (rouge).

2 −3
Racine : x = 1,5 — f(x) < 0 pour x < 1,5 et f(x) > 0 pour x > 1,5
Attention : Ne pas confondre le signe de la fonction (positif/négatif) avec ses variations (croissante/décroissante). Une fonction peut être croissante et négative en même temps !

5. Problèmes concrets

Comparaison de deux offres tarifaires

Situation : Deux fournisseurs d’accès Internet proposent :

  • Offre A : Abonnement de 10 €/mois + 0,50 € par Go consommé
  • Offre B : Abonnement de 25 €/mois + 0,20 € par Go consommé

On modélise par : f(x) = 0,5x + 10 et g(x) = 0,2x + 25

Seuil de rentabilité
Les deux offres coûtent le même prix quand f(x) = g(x), soit :
0,5x + 10 = 0,2x + 25 ⇒ 0,3x = 15 ⇒ x = 50 Go
Coût à l’égalité : f(50) = 0,5 × 50 + 10 = 35 €

Autres applications courantes

Vitesse et distance

Un véhicule roule à vitesse constante v. La distance parcourue est d(t) = v × t (fonction linéaire).

S’il part d’un point situé à d0 km de l’origine : d(t) = v × t + d0 (fonction affine).

Conversions de température

De Celsius vers Fahrenheit : F(C) = 1,8C + 32

C’est une fonction affine avec a = 1,8 et b = 32.

6. Exercices type Brevet

Exercice 1 — Identifier une fonction linéaire

Parmi les fonctions suivantes, lesquelles sont linéaires ?

a) f(x) = 3x   b) g(x) = 2x + 5   c) h(x) = −4x   d) k(x) = x²

Voir la correction

a) f(x) = 3x : Oui, c’est une fonction linéaire de coefficient 3.

b) g(x) = 2x + 5 : Non, c’est une fonction affine (b = 5 ≠ 0).

c) h(x) = −4x : Oui, c’est une fonction linéaire de coefficient −4.

d) k(x) = x² : Non, ce n’est ni linéaire ni affine (c’est une fonction polynôme du second degré).

Exercice 2 — Calculer des images

Soit f la fonction affine définie par f(x) = −2x + 7.

Calculer f(0), f(3), f(−1) et f(3,5).

Voir la correction

f(0) = −2 × 0 + 7 = 7

f(3) = −2 × 3 + 7 = −6 + 7 = 1

f(−1) = −2 × (−1) + 7 = 2 + 7 = 9

f(3,5) = −2 × 3,5 + 7 = −7 + 7 = 0

Remarque : f(3,5) = 0 signifie que 3,5 est l’antécédent de 0, c’est-à-dire la racine de la fonction.

Exercice 3 — Déterminer une fonction affine

La droite représentant une fonction affine f passe par les points A(2 ; 5) et B(6 ; 13).

Déterminer l’expression de f(x).

Voir la correction

Calcul de a :

a = 13 − 56 − 2 = 84 = 2

Calcul de b :

f(2) = 5, donc 2 × 2 + b = 5, soit 4 + b = 5, d’où b = 1.

Conclusion : f(x) = 2x + 1

Vérification : f(6) = 2 × 6 + 1 = 13 ✓

Exercice 4 — Problème de tarification

Un cinéma propose deux formules :

  • Formule 1 : 8 € par séance
  • Formule 2 : Abonnement de 15 € par mois + 5 € par séance

a) Exprimer le coût de chaque formule en fonction du nombre x de séances.
b) À partir de combien de séances la formule 2 devient-elle plus avantageuse ?

Voir la correction

a) Formule 1 : f(x) = 8x (fonction linéaire)
Formule 2 : g(x) = 5x + 15 (fonction affine)

b) On cherche quand g(x) < f(x) :

5x + 15 < 8x

15 < 3x

x > 5

Conclusion : À partir de 6 séances par mois, la formule 2 est plus avantageuse.

Vérification : Pour 5 séances : f(5) = 40 € et g(5) = 40 € (identique).
Pour 6 séances : f(6) = 48 € et g(6) = 45 € ✓

Exercice 5 — Lecture graphique

Une droite passe par les points de coordonnées (0 ; −2) et (3 ; 4).

a) Cette droite représente-t-elle une fonction linéaire ou affine ?
b) Déterminer son expression.
c) Quel est l’antécédent de 0 ?

Voir la correction

a) La droite passe par (0 ; −2), donc l’ordonnée à l’origine est b = −2 ≠ 0. C’est une fonction affine.

b) a = 4 − (−2)3 − 0 = 63 = 2

Donc f(x) = 2x − 2

c) Antécédent de 0 : 2x − 2 = 0 ⇒ 2x = 2 ⇒ x = 1.

L’antécédent de 0 est 1.

Exercice 6 — Problème ouvert (type Brevet)

Un réservoir contient 200 litres d’eau. On ouvre un robinet qui laisse s’écouler l’eau à raison de 12 litres par minute.

a) Exprimer le volume V(t) d’eau restant en fonction du temps t (en minutes).
b) Quelle est la nature de cette fonction ? Préciser a et b.
c) Au bout de combien de temps le réservoir sera-t-il vide ?
d) Le volume est-il toujours positif ? Préciser le domaine de validité du modèle.

Voir la correction

a) V(t) = −12t + 200

b) C’est une fonction affine avec a = −12 (le volume diminue de 12 L chaque minute) et b = 200 (volume initial).

c) Le réservoir est vide quand V(t) = 0 :
−12t + 200 = 0 ⇒ 12t = 200 ⇒ t = 20012 = 503 ≈ 16,7 minutes

Le réservoir sera vide au bout de 16 minutes et 40 secondes.

d) Le volume ne peut pas être négatif (pas de sens physique). Le modèle est valide pour 0 ≤ t ≤ 503 soit environ 0 ≤ t ≤ 16,7 minutes.
