I. Équations du premier degré

Définition

Une équation du premier degré à une inconnue x est une égalité de la forme ax + b = 0, où a et b sont des nombres donnés et a ≠ 0.

Résoudre une équation, c’est trouver toutes les valeurs de x qui rendent l’égalité vraie. Ces valeurs sont les solutions.

Règles fondamentales :
• On peut ajouter ou soustraire un même nombre aux deux membres.
• On peut multiplier ou diviser les deux membres par un même nombre non nul.

Méthode pas à pas : résoudre ax + b = cx + d

Étape 1 : Regrouper les termes en x d’un côté (soustraire cx des deux membres).

Étape 2 : Regrouper les constantes de l’autre côté (soustraire b des deux membres).

Étape 3 : Diviser par le coefficient de x.

Étape 4 : Vérifier en remplaçant x par la solution trouvée.

Pensez à l’image d’une balance : ce que vous faites à gauche, vous devez le faire à droite pour maintenir l’équilibre.

Exemple détaillé

Résoudre : 3x + 7 = x + 15
3x + 7 − x = x + 15 − x  ⇒  2x + 7 = 15
2x + 7 − 7 = 15 − 7  ⇒  2x = 8
x = 82 = 4

Vérification : 3×4 + 7 = 19 et 4 + 15 = 19 ✓

II. Équations produit nul

Propriété fondamentale

Un produit de facteurs est nul si et seulement si au moins un des facteurs est nul.

A × B = 0 ⇔ A = 0 ou B = 0

Méthode

1. Mettre l’équation sous forme factorisée : (ax + b)(cx + d) = 0

2. Appliquer la propriété : résoudre ax + b = 0 et cx + d = 0 séparément.

3. L’équation admet deux solutions (ou une solution double si les deux équations donnent la même valeur).

Exemple 1

Résoudre : (2x − 6)(x + 4) = 0
Soit 2x − 6 = 0 ⇒ 2x = 6 ⇒ x = 3
Soit x + 4 = 0 ⇒ x = −4

L’équation admet deux solutions : x = 3 et x = −4.

Cas particulier : factorisation préalable

Résoudre : x² − 5x = 0
On factorise par x : x(x − 5) = 0
Soit x = 0, soit x − 5 = 0 ⇒ x = 5

Solutions : x = 0 et x = 5.

Exemple avec identité remarquable

Résoudre : x² − 9 = 0
On reconnaît a² − b² = (a − b)(a + b) avec a = x et b = 3
(x − 3)(x + 3) = 0
x = 3 ou x = −3
Avant d’appliquer cette propriété, le second membre doit être zéro. Si ce n’est pas le cas, développez, réduisez, passez tout à gauche, puis factorisez.

III. Mise en équation de problèmes

Méthode générale

1. Choix de l’inconnue : identifier la grandeur cherchée et la noter x.

2. Mise en équation : traduire l’énoncé en une égalité mathématique.

3. Résolution : résoudre l’équation obtenue.

4. Vérification et conclusion : vérifier que la solution a du sens dans le contexte et rédiger une phrase-réponse.

Lexique de traduction :
« la somme de » → +  « la différence » → −  « le double » → 2x  « le triple » → 3x
« la moitié » → x2  « le tiers » → x3  « de plus que » → +  « de moins que » → −

Problème 1 — Âges

Paul a 14 ans. Son père a 42 ans. Dans combien d’années l’âge du père sera-t-il le double de celui de Paul ?

Solution guidée

Inconnue : x = nombre d’années cherché.

Équation : Dans x années, Paul aura 14 + x ans et son père 42 + x ans.

42 + x = 2(14 + x)
42 + x = 28 + 2x
42 − 28 = 2x − x ⇒ 14 = x

Réponse : Dans 14 ans, le père aura le double de l’âge de Paul.

Vérification : Paul aura 28 ans, son père 56 ans. 56 = 2 × 28 ✓

Problème 2 — Géométrie

Un rectangle a un périmètre de 54 cm. Sa longueur dépasse sa largeur de 7 cm. Quelles sont ses dimensions ?

Solution guidée

Inconnue : x = largeur en cm. Alors longueur = x + 7.

P = 2(x + x + 7) = 54
2(2x + 7) = 54 ⇒ 2x + 7 = 27
2x = 20 ⇒ x = 10

Réponse : Largeur = 10 cm, longueur = 17 cm.

Vérification : 2 × (10 + 17) = 2 × 27 = 54 ✓

Problème 3 — Prix

Un commerçant vend des cahiers et des stylos. Un cahier coûte 2 € de plus qu’un stylo. Julie achète 3 cahiers et 5 stylos pour 29 €. Quel est le prix d’un stylo ?

Solution guidée

Inconnue : x = prix d’un stylo en euros. Prix d’un cahier = x + 2.

3(x + 2) + 5x = 29
3x + 6 + 5x = 29 ⇒ 8x = 23
x = 238 = 2,875

Réponse : Un stylo coûte 2,88 € (arrondi au centime) et un cahier 4,88 €.

IV. Inéquations

Définition

Une inéquation est une inégalité comportant une inconnue. Résoudre une inéquation, c’est trouver toutes les valeurs de l’inconnue qui vérifient l’inégalité.

L’ensemble des solutions est un intervalle, représenté sur une droite graduée.

Règle capitale : quand on multiplie ou divise les deux membres par un nombre négatif, on change le sens de l’inégalité.

Exemple 1

Résoudre : 3x − 5 > 7
3x > 7 + 5 ⇒ 3x > 12
x > 4

L’ensemble des solutions est ]4 ; +∞[.

Exemple 2 (attention au signe !)

Résoudre : −2x + 3 ≤ 9
−2x ≤ 9 − 3 ⇒ −2x ≤ 6
On divise par −2 : on change le sens
x ≥ −3

L’ensemble des solutions est [−3 ; +∞[.

Notation sur la droite graduée

• Un point plein ● signifie que la borne est incluse (≥ ou ≤).

• Un point vide ○ signifie que la borne est exclue (> ou <).

• La zone colorée représente l’ensemble des solutions.

Pour retenir le changement de sens : quand on multiplie par un négatif, les grands deviennent petits et les petits deviennent grands. Exemple : 2 < 5 mais −2 > −5.

V. Systèmes d’équations (initiation)

Qu’est-ce qu’un système ?

Un système de deux équations à deux inconnues est un ensemble de deux équations que l’on doit vérifier simultanément.

Graphiquement, résoudre un système revient à trouver le point d’intersection de deux droites.

Méthode par substitution :
1. Exprimer une inconnue en fonction de l’autre dans l’une des équations.
2. Remplacer dans l’autre équation.
3. Résoudre l’équation obtenue (une seule inconnue).
4. En déduire la valeur de l’autre inconnue.

Exemple

Résoudre le système :
y = 2x + 1  (1)
3x + y = 11  (2)

Substitution de (1) dans (2) :

3x + (2x + 1) = 11
5x + 1 = 11 ⇒ 5x = 10 ⇒ x = 2
y = 2 × 2 + 1 = 5

La solution est (x ; y) = (2 ; 5).

Choisissez d’exprimer l’inconnue qui a le coefficient le plus simple (idéalement 1) pour faciliter la substitution.

Interprétation graphique

Chaque équation du système représente une droite dans le plan.

• Si les droites se coupent : une solution unique (le point d’intersection).

• Si les droites sont parallèles : aucune solution.

• Si les droites sont confondues : infinité de solutions.

VI. Exercices progressifs (type Brevet)

Résoudre l’équation : 5x − 3 = 2x + 9

Correction
5x − 2x = 9 + 3 ⇒ 3x = 12 ⇒ x = 4
Vérification : 5×4 − 3 = 17 et 2×4 + 9 = 17 ✓

Résoudre : (x − 3)(2x + 8) = 0

Correction
x − 3 = 0 ⇒ x = 3  ou  2x + 8 = 0 ⇒ x = −4
Solutions : x = 3 et x = −4.

Résoudre l’inéquation : 4x + 1 ≥ 2x − 7

Correction
4x − 2x ≥ −7 − 1 ⇒ 2x ≥ −8 ⇒ x ≥ −4
Ensemble des solutions : [−4 ; +∞[

Un rectangle a une longueur qui mesure le triple de sa largeur. Son périmètre est 56 cm. Trouvez la largeur.

Correction
Soit x la largeur. Longueur = 3x.
P = 2(x + 3x) = 56 ⇒ 8x = 56 ⇒ x = 7 cm.
Largeur = 7 cm, longueur = 21 cm. Vérification : 2×(7+21) = 56 ✓

Développer puis résoudre : (x + 3)² − (x − 2)² = 25

Correction
(x+3)² = x² + 6x + 9   (x−2)² = x² − 4x + 4
x² + 6x + 9 − (x² − 4x + 4) = 25
x² + 6x + 9 − x² + 4x − 4 = 25
10x + 5 = 25 ⇒ 10x = 20 ⇒ x = 2
Vérification : (2+3)² − (2−2)² = 25 − 0 = 25 ✓

Résoudre le système par substitution :
x + y = 10   et   2x − y = 5

Correction
De la première équation : y = 10 − x. On remplace dans la seconde :
2x − (10 − x) = 5 ⇒ 2x − 10 + x = 5 ⇒ 3x = 15 ⇒ x = 5
y = 10 − 5 = 5
Solution : (x ; y) = (5 ; 5).
Vérification : 5 + 5 = 10 ✓   2×5 − 5 = 5 ✓
